Welcome to the MagicPad!

This is my attempt to create a smarthome control device. 
Recently I've made a couple smart devices controlled by esp32s, so I wanted to make a device that could control them. 
The two devices it's set up to control right now are my coffee maker and my alarm clock. 
Because these are both custom projects, I don't see the MagicPad's current firmware being useful to anyone else, but that hardware can be used to control any device that can be controlled over wifi!
Because of how versatile the hardware is, it has plenty of room for future expansion such as adding games!

Assembly:
- Pretty self-explanatory for the most part, just solder the components where they are in the 3d model. 
- The one tricky part is the battery.
- To connect the battery, solder the negative wire from the battery holder into the hole in the board to the right of the buttons. 
- After this, directly solder the positive wire to the positive pin on the battery connector of the ESP32. 
- To determine which one a the positive pin, a multimeter on beeper mode can be used between both pins and ground. if it beeps, that pin is negative. 
- You also might need some additional dupont connectors to raise the screen up so it's not swallowed by the case

  Useage:
- I think the UI is pretty self-explanatory and probably no one else is ever gonna use it, so I'm not gonna bother explaining it. 
- The switch in the bottom right is a power switch
- I know this is bad design, but the device needs to be powered ON in order for it to charge. 
- Bottom left button is a back button and top right is a home button. 
- You need to input wifi and IP information in the sketch before you upload it
